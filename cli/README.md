**Nice Router CLI** allows you to start, manage, and monitor your Nice Router server directly from the command line.

---

## ⚡ Quick Start

```bash
# Start Nice Router server
nice-router
# or run with node
node custom-server.js --port 20127
```

🎉 Dashboard will open automatically at:
`http://localhost:20127`

For the complete documentation and setup guide, please refer to the [main README](../README.md).
